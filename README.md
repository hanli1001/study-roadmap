## 📐 整理记录（2026.09.28）

**动因**：根目录 78 个条目，其中 18 个是被 gitignore 的 `*.bak-*`、15 个是 7 月的练习代码 —— 找不到东西。

**结果**：78 → **28**。移动 31 个文件、归位 24 份备份、删 3 个缓存目录、改写 86 处文档引用。

**原则**（下次整理照这个来）：
1. **天天要用的留根目录**，不为了"整齐"埋深。
2. **按"这是什么"分，不按时间分**。
3. **成套的文件夹内部有相对链接 → 一律不动**（`交互演示/`、`每周书/` 等）。
4. **搬完必须证明没搬断**：`check_paths.py` 差分 + **跑一遍 `pytest`**（见下面第 2 条）。

**⚠️ 从这次整理里学到的两条（已记进 `改动路线.md` 的 W 表）**：
1. **静态引用检查过了 ≠ 真的没坏**：`api.py` / `prescription_db.py` 里的库路径是**相对 cwd** 的，`pytest.ini` 只能往上找 —— 这两个问题**引用检查器一个都查不出来**，是跑 `pytest` 才暴露的（当场 5 个测试红）。现在都改成了"跟着脚本自己走"。
2. **dry-run 必须挡住每一个副作用**：我的 `--dry` 只挡住了 `shutil.move`，`git mv` 照样执行 → "试运行"真的搬走了 2 个文件。

**老路径去哪了**：原来在根目录的 `第N课-*` / `teaching-methodology*` → `课程/`；
`api.py` / `prescriptions.db` / `sql-notes.md` 等 → `我的练习/`；
`政策与趋势-*.md` / `职业方向评估-*.md` → `职业探索/`；所有 `*.bak-*` → `_备份/`。
