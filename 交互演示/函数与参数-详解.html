③ 四种参数（本课核心，一次讲清）

种类写法什么时候用 / 规则
① 位置参数def f(a, b)必须按顺序给全。少给/多给都报错
② 默认参数def f(a, b=2)不传就用默认值。有默认值的必须排在没有的后面
③ 关键字参数f(a=1, b=3)调用时点名给，顺序随便，可读性最好
④ 可变参数def f(*args, **kwargs)*args 收多余的位置参数成元组；**kwargs 收多余的关键字参数成字典
⚠️ 顺序铁律：def f(普通参数, *args, 有默认值的, **kwargs) —— 位置参数 → 可变位置 → 默认 → 可变关键字
⚠️ 默认参数陷阱（面试常考）：def f(x, lst=[]) —— 这个空列表只创建一次，多次调用会共享、越积越多。
要可变默认值就写 lst=None，函数里再 if lst is None: lst = []

⑤ 返回值 return：函数怎么把结果交出来



  

    
写法返回说明

    
不写 returnNone你的 link() 就是这种：只干活、不交结果

    
return xx最常见

    
return a, b(a, b) 元组"返回多个值"其实是返回一个元组 → 调用处可解包 x, y = f()

    
return（光秃秃）None用来提前结束函数（相当于 break 整个函数）

  

  
⚠️ return 之后的代码永远不执行（和循环里的 break 一个道理）。

  
💡 print vs return 的区别（新手最大的坎）：

    print = 给人看（屏幕上显示，程序拿不到）；return = 给程序用（可以继续计算、存起来）。

    你写 x = link(...) 得到的是 None，正因为 link 只 print/insert 没有 return。






⑥ 作用域：函数里的变量，外面看不见




def calc():
    temp = 10        # 局部变量：只活在函数内部
    return temp * 2

print(calc())       # 20 ✅
print(temp)         # ❌ NameError: name 'temp' is not defined

  

    
变量在哪谁能看见例子

    
函数内定义只有函数内temp（上面那个）

    
函数外定义（全局）函数内能读conn / cur（你脚本里就是这么用的）

    
函数内改全局要 global不写 global 直接赋值 → 会新建一个局部变量（坑）
