len() 详解

签名 · 参数种类 · 返回类型 · 异常 · 类型对照 —— 边拧边看。配套：样例代码库/len用法.py

① 它长什么样（签名）

len(obj) → int
部位名字含义
len函数名length（长度）的缩写 —— 数一数里面有多少个
obj参数名要数的东西。**只能传"有长度"的类型**（见③）
→ int返回类型返回一个整数（永远不是小数、不是字符串）
💡 括号里的 obj 是"参数"，箭头右边是"返回类型"。以后看任何函数都先找这两样。

② 参数种类：它能吃什么、不能吃什么

✅ 能数（有长度）
类型写法len 结果数的是什么
str 字符串"abc"3字符个数（中文 / 空格 / 标点各算 1）
list 列表[1,2,3]3元素个数（嵌套的列表整体算 1 个）
tuple 元组(1,2)2元素个数
dict 字典{"a":1}1键的个数（不是键值对！）
set 集合{1,2,3}3元素个数（重复的会被去掉）
rangerange(5)5它有明确长度，所以能数
❌ 不能数（会报 TypeError）
类型写法为什么不能
int / float123数字没有"长度"这个概念（想数位数要 len(str(123))）
NoneNone空的东西，没有长度（要判空用 if x is None）
生成器 / 迭代器(x for x in ...)它不知道后面还有多少个，而且只能用一次 → 先 list() 转成列表
boolTrue真/假没有长度

⑤ 常见用法（4 种，都是真代码）

# 1) 判空：最常见
names = []
if len(names) == 0:
    print("还没有人")      # 等价写法：if not names:

# 2) 循环遍历下标
data = ["甲", "乙"]
for i in range(len(data)):
    print(i, data[i])            # 更 Python 的写法是 enumerate(data)

# 3) 校验用户输入长度
pwd = "abc"
if len(pwd) < 6:
    print("密码太短")

# 4) 数"数字有几位"（先转字符串）
print(len(str(12345)))           # 5

💡 报错信息里的 has no len() = "这个东西没有长度" —— 见到它就想到"类型不对"。
