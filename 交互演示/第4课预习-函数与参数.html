开课前：闭卷答这 4 题（3 分钟，别翻笔记）

这是第 1–3 课的检索练习，不是你今天要学的新东西。答不出很正常，答不出才说明该练。

① 多对多为什么必须用第三张表？

因为「谁选了哪门课」这个事实同时跟着两个人走 —— 放在学生表里，一个学生只能有一门课；放在课程表里，一门课只能有一个学生。它自己就是第三种东西，得有自己的表。那张表一行 = 一条关系，不是一个人。

② ON 和 WHERE 的区别？

ON = 怎么配（配对规则，写在 JOIN 后面）；WHERE = 要哪些（筛结果）。第 3 课上实测过：少了 WHERE，那本书的例子从 2 行变成 3 行。

③ COUNT(*) 和 COUNT(age) 什么时候不一样？

有 NULL 的时候。COUNT(*) 数行数，不管里面是不是空；COUNT(列名) 跳过 NULL。所以 COUNT(age) 可能比 COUNT(*) 小。

④ 你 sql-notes.md 里记的药材数，和你 COUNT(*) 数出来的一样吗？

这是第 3 课欠下的作业，要你自己去数（笔记写的是一个数，库里是另一个）。
目的不是对答案，是让你亲眼见一次：笔记会过期，库不会 —— 以后凡是"我记得有 X 条"，都要能当场数一遍。

钩子：你已经写过 8 遍的东西

打开 我的练习/prescription_db.py，翻到第 80 行往下 —— 有 8 行长得一模一样的调用：

link("麻黄汤", [("麻黄", "三两"), ("桂枝", "二两"), ("杏仁", "七十个"), ("甘草", "一两")])
link("桂枝汤", [("桂枝", "三两"), ("白芍", "三两"), ("甘草", "二两"), ("生姜", "三两"), ("大枣", "十二枚")])
link("小柴胡汤", [("柴胡", "半斤"), ("黄芩", "三两"), ("人参", "三两"), ("半夏", "半升"), ...])
...                              ← 一共 8 行

它们都指向同一个函数（第 68 行）：

def link(fangji_name, ingredients_dosage):
    """辅助函数：给方剂关联药材"""

先自己算，再往下看：

  1. 这 8 行如果不用函数，大概要写多少行？
  2. 如果以后要把"药材"改成"饮片"，不用函数要改几处？用了函数呢？

函数 = 把一串重复动作打包成一个名字。就这一句。这一课不是教你写函数，是教你叫出它的各个部位的名字。

先猜：下面这一行会打出什么？

x = link("麻黄汤", [])
print(x)

选一个（上课时会当场跑给你看）：

  1. 报错 —— 因为 link() 没有返回值
  2. 打出 None
  3. 打出 []（空列表）
  4. 打出插入结果 / 影响的行数

⚠️ 先写在纸上再往下 —— 猜错比猜对值钱。这是本课靶子 ② 的入口， 也是本课 L3 要你讲给我的那句话（顺便补上第 3 课没验的「讲给别人听」那一档）。

课后三个任务（上完课做）

  1. greet(name, greeting="你好") —— 返回问候语（不是 print）
  2. greet("小明") 与 greet("小红", "早上好") 各调用一次并打印出来
  3. 进阶：add_all(*nums) —— 把所有数字加起来返回

第 1、2 题考的是靶子 ①（默认值从哪来）+ 靶子 ②（返回 ≠ 打印）。 第 3 题只是"见识"一下 *args，做不出不算欠账。

验收：三级（上完课当场对）

级别通过标准
L1能指出自己 link() 里哪些是参数、返回什么、为什么要写函数
L2独立写出 greet()（含默认参数），并说清 greet("小明") 时 greeting 从哪来
L3能讲：为什么 x = link(...) 得到 None ＋ 位置参数和关键字参数什么时候必须用哪种

🔴 L3 这一档这次要补一个旧账：第 3 课的 ⑤ 换皮 / ⑥ 你讲我听 你决定略过了， 所以「能讲给别人听」从来没验过。这次不重开第 3 课 —— 改成： 你把「为什么是 None」讲给我听，讲顺了，两课的 L3 一起算过。

⚠️ 老规矩：你说「我懂了」的时候就是危险信号 —— 立刻去交互卡 ④ 点"少给 / 多给"两个按钮自证。
