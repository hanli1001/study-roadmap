range() 详解

签名 · 三种形态 · 返回类型 · 与 len/list 的关系 · 推导式 · 常见异常。配套：样例代码库/range用法.py

① 它长什么样（签名）

range(start, stop[, step]) → range 对象
参数类型必填？含义
startint可选（默认 0）从哪个数字开始，包含
stopint必需到哪个数字停，不包含（左闭右开）
stepint可选（默认 1）每次加多少；可以是负数（倒着数）
返回值range 对象—不是列表！是一个"会按需生成数字的懒对象"（见④）
💡 只给一个参数时，它是 stop（不是 start）：range(5) = 0,1,2,3,4

② 一条铁律 + 一个记忆法

终点取不到（左闭右开）：range(1, 5) → 1,2,3,4，没有 5
记忆法：range 像"数数到门槛前就停" —— 说"走到第 5 个"就停在第 5 个之前。
想要 1~5 就写 range(1, 6)；想要"重复 n 次"就写 range(n)。
为什么这样设计？因为编程里 99% 的循环都是"走 n 次"或"走一遍下标"，0 起、取不到终点最顺手。

④ 返回类型：它不是列表（这是新手最大的误会）



  

    
写法结果说明

    
range(3)range(0, 3)打印出来长这样 —— 不是 [0,1,2]

    
list(range(3))[0, 1, 2]要看内容就转列表

    
len(range(3))3能数！因为它知道自己有多少个

    
range(3)[1]1能按下标取（支持切片和索引）

    
3 in range(5)True能判断"在不在里面"

    
range(3) == [0,1,2]False它和列表不是同一种东西

  

  
为什么要设计成"懒对象"？range(100000000) 如果是列表，要立刻占几百 MB 内存；

    懒对象只记住 start/stop/step 三个数，用的时候现算 —— 省内存。同一个套路还有 enumerate、生成器。






⑤ 最常见的用法：for 循环（3 种写法对应 3 种需求）




# 写法 1：只要重复 n 次，不要数字
for _ in range(3):
    print("跑一次")        # 跑 3 次（习惯用 _ 表示"我不关心这个变量"）

# 写法 2：要用到数字
for i in range(3):
    print(i)               # 0 1 2

# 写法 3：走一遍下标（要按位置取别的东西）
names = ["甲", "乙", "丙"]
for i in range(len(names)):
    print(i, names[i])     # 更 Python 的写法：enumerate(names)

  
💡 判断标准：只要次数 → range(n)；要序号又要值 → enumerate()；要下标做复杂计算 → range(len(x))。






⑥ 搭配推导式：一行造列表




# 0~9 的平方
[x*x for x in range(10)]              # [0,1,4,9,...,81]

# 0~9 里的偶数（条件放 for 后面！）
[x for x in range(10) if x % 2 == 0]   # [0,2,4,6,8]

# 倒着来
[x for x in range(10, 0, -1)]          # [10,...,1]

  
⚠️ 你踩过的坑（P-006）：条件要放在 for 后面；只有带 else 的才是三元表达式。

⑧ 空 range 的三种情况（循环体一次都不执行）



  

    
写法结果为什么空

    
range(0)空从 0 开始、到 0 停，一步都走不了

    
range(5, 5)空起点 == 终点

    
range(5, 1)空步长是正的，但起点 > 终点 → 不会自动倒过来

    
range(1, 10, -1)空步长是负的，但起点 < 终点

  

  
⚠️ 空 range 不报错，循环体静默不执行 —— 这是"我明明写了循环却没输出"的最常见原因。
