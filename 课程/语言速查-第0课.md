# 第 0 课 · 语言菜单（教学卡片）

> 配套：`teaching-methodology.md`（教学法 v2）· 第 0 课 · 预计 20 分钟 · 不写代码
> 目标：让纯小白在上一张"什么语言干什么事"的职业地图，知道**自己从哪个岗位入门**
> 使用方式：按五步法带课，卡片即教案；课后发 3 张复习卡（见文末）

---

## ① 钩子 + 先猜（3 分钟）

**开场问（别先讲答案）**：
> "你想开一家餐厅……你最想先招哪种人？大厨？收银员？传菜的？"
> "那写软件也一样——**先不着急学哪门语言，先知道'这家餐厅'里都有哪些岗位**。今天先猜一个：全世界最多程序员在干的活，用的是哪种语言？"

先让学员猜，猜到哪算哪（生成效应：猜错记得更牢）。

---

## ② 类比引入（5 分钟）：语言 = 餐厅里的岗位

| 语言 | 岗位类比 | 一句话特点 | 擅长 | 不擅长 |
|------|----------|------------|------|--------|
| **Python** | 万金油厨子 | 什么菜都会做，上手最快，做宴席大菜就吃力 | AI/数据分析/脚本/Web 后端/爬虫 | 游戏引擎、高频交易、移动端、浏览器前端 |
| **JavaScript / TypeScript** | 端盘服务员 | 顾客面前（浏览器里）**唯一能说话的人**；也能钻进后厨（Node.js） | 前端（绝对统治）、聊天室/实时推送、小程序、一个人做全栈 | CPU 密集型计算、系统底层 |
| **Java** | 大堂经理 | 银行/大企业餐厅必备；稳如磐石，就是官腔多（代码啰嗦） | 大型企业后端、微服务、大数据（Hadoop/Spark/Flink） | 快速写小脚本、前端、底层 |
| **Go** | 传菜机器人 | 为大客流（云端）而生：Docker、Kubernetes 就是它造的；简单又跑得快 | 高并发后端、云原生/DevOps、命令行工具 | 前端、AI/数据科学、复杂业务抽象 |
| **C / C++** | 灶台/后厨工程师 | 餐厅真正的地基——炉灶、水管、电网；手艺顶级，学徒期最长 | 操作系统、嵌入式、数据库引擎（MySQL/SQLite/Redis 核心）、游戏引擎、AI 框架底层 | 快速开发（写起来慢、调试痛苦）、Web/移动端 |
| **Rust** | 后厨安全工程师 | 手艺和 C++ 差不多，但**绝不煤气泄漏**（内存安全）；新派，还在抢 C++ 的活 | 系统编程、高性能安全后端、命令行工具、区块链 | 学习曲线陡（新手会抓狂）、快速原型 |
| **Swift / Kotlin** | 甜品站 / 饮品吧 | 苹果店、安卓店各自的专属柜台（手机 App） | iOS（Swift）/ Android（Kotlin） | 各自平台之外不通用 |
| **SQL** | 仓库管理员 | 不算大厨，但**所有餐厅都要**：记每一味食材（数据）。你点完菜，它去仓库翻货 | 建表、查询、联表、统计 | 它不是"编程语言"（没有逻辑运算），但人人必会 |
| **HTML / CSS** | 菜单印刷工 | 菜单的骨架（HTML）+ 皮肤（CSS）；不算做菜，但没它顾客看不出店里卖什么 | 网页结构 + 样式 | 没有逻辑，要配 JS 才有交互 |
| **自然语言指令（Prompt）** | 点菜 AI 主管 | **2026 年的新岗位**：直接对 AI 店长说人话（"帮我做一桌八菜一汤"），就能指挥整家餐厅 | 指挥 AI 写代码、定方向、做判断 | 你每天在练的这个——就是第 0 课的主角之一 |

> ⚠️ 教学用素材自查：转抄资料已删韩文乱码、"Java 仍是 Android 主力"已改为"Kotlin 为主"。

## ③ 示例-问题对（5 分钟）：逐条看"速查表"

给学员看下面这张 **做完事速查表**，**逐条问他"为啥是它？"**（他先说，你再补）：

| 你想做的事 | 首选语言 | 备选 |
|------------|----------|------|
| 做网站前端 | JavaScript/TypeScript | — |
| 做网站后端 | Java / Go | Python、Node.js |
| 做手机 App | Swift(iOS) / Kotlin(Android) | Flutter(Dart)、React Native(JS) |
| 做 AI / 机器学习 | Python | — |
| 做数据分析 | Python | R、Julia |
| 做游戏 | C++ | C#(Unity) |
| 做操作系统/驱动 | C / Rust | C++ |
| 做爬虫/自动化脚本 | Python | — |
| 做云原生/DevOps 工具 | Go | Rust |
| 做区块链 | Rust / Solidity | Go |
| 快速写小工具验证想法 | Python | JavaScript |

**带读话术示例**："做 AI 为什么是 Python？——因为 AI 的大厨（PyTorch/TensorFlow）是用 Python 教人点菜的，跟它说话最方便。那做游戏为什么不选 Python？——因为游戏要 60 帧不卡，万金油厨子跑不动，得请灶台工程师 C++。"

## ④ 自我解释（3 分钟）：为什么大饭店要养这么多岗位？

**提问链**（学员自己答，导师只补充）：
1. "为什么不能只招一个万金油厨子（Python）干完所有活？" → 每个岗位各有所长：有的炒菜快（Python），有的能掌大店（Java），有的火候极致（C++），有的服务顾客（JS）
2. "那为什么小馆子（小公司）只招一两个厨子？" → 人少，一人多岗；所以**你一个人也能用 Python 做出完整产品**（你已经做到了——方剂 API！）
3. "你最想站在哪个岗位？" → 让学员说出自己的答案（这是本课的收口）

## ⑤ 变式练习（4 分钟）+ 个人裁剪标注

**变式题（闭卷，4 分钟）**：

1. **变式 1**：你明天去科大讯飞实习（后端主力语言是 Java），店长（导师）最想让你先学哪个岗位？→ Java 大堂经理 + Python 厨子（你已有）
2. **变式 2**：给中医诊所做一个"方剂智能推荐"小程序，需要配哪几个岗位（语言）？→ Python（AI）+ SQL（数据）+ JavaScript（前端界面）
3. **变式 3**（反着问）：想给 Chrome 浏览器写底层引擎，招万金油厨子行吗？→ 不行，那是灶台工程师 C++ 的活

**个人裁剪版（医疗 AI 编排师 · 2026.09 实况）**：

| 语言 | 状态 | 备注 |
|------|------|------|
| Python | ✅ 已上岗（主线） | 不用换 |
| SQL | ✅ 已毕业 | 8 方剂 × 37 药材实战过 |
| Java | 📋 大二暑假上岗 | 讯飞后端主力（第二语言） |
| JavaScript/TypeScript | ⚠️ 只学前端 Vue | 产品交付需要；React 不学 |
| Go / Rust / Swift / Kotlin / 区块链 | ❌ 不学 | 无场景（见不学清单） |
| C / C++ | ⏸ 认识即可 | 以后 MLOps 讲量化部署会听到，懂概念就行 |
| **自然语言指令** | 🔥 天天在练 | AI 教练规范（教学法 v2 第五章）——你的第 2 门"语言" |

## 课后三张复习卡（间隔复习：当天 → 隔天 → 3 天 → 7 天 → 30 天）

```
【卡片 1 · 概念】问："Python 最适合干哪 3 件事？做什么事一定要换 Java？"
               答(学员闭卷)：AI/数据/脚本(爬虫/自动化)……大型企业后端(银行/电商/讯飞)用 Java
【卡片 2 · 连线】问(闭卷连线)："做游戏 → ?；做 AI → ?；做前端 → ?；做云原生 → ?"
               答：C++；Python；JS/TS；Go
【卡片 3 · 判断对错】问："①C++ 写 Web 应用很快 ✅/❌ ②Go 是云端的传菜机器人 ✅/❌ ③HTML 是编程语言 ✅/❌"
               答：①❌(浏览器/企业后端不选它) ②✅ ③❌(没逻辑运算)
```

## 导师自查清单（课前过一遍）

- [ ] 开场有没有让学员**先猜**（生成效应）？——不要直接念表格
- [ ] 类比有没有落到**学员自己生活**（餐厅/菜市场）？——他从来没进过餐厅就换"学校食堂/超市"类比
- [ ] 速查表是不是**逐条让学员先说**，而非你念？（检索练习）
- [ ] 4 分钟变式题发下去就是**闭卷**（不看表）？
- [ ] 三张复习卡课后立刻发给学员？
