【A】题 1 · 预测（不许跑代码）
----------------------------------------------------------
    题目：  x = link("麻黄汤", [])
            print(x)         打出什么？

    他的答案： B（None）
    他的理由：「函数没有 return，默认返回是 none；其次 return 是给程序用的，存储值」

    ✅ 判：过（答案 + 理由都对 = 靶子 ② 命中）

----------------------------------------------------------
【B】题 2 · 换皮（2 分钟，不查资料）
----------------------------------------------------------
    题目：  x = greet("小红","早上好")  -> 早上好，小红
            y = greet("小明")           -> 你好，小明

    他写的（原样，一字未改）：
        def greet(a, b="你好"):
            x = f"{b},{a}"
            return x

    实跑输出：
        早上好,小红
        你好,小明
        greet('小红','早上好') -> '早上好,小红' | 类型 str
        greet('小明')          -> '你好,小明'   | b 没传 -> 取默认值 '你好'

    ✅ 判：过
       · 用了 return 而不是 print —— **正好避开我埋的那个坑**
       · 两个调用都正确：第二个靠"不传就取默认值"
       · 小注：分隔符用的是半角逗号（题目里写的是全角，属吹毛求疵，不算错）
       · 🔑 唯一可挑的：参数名 `a` / `b` ——
         本课的主题就是"给动作贴名字"，自己写的时候用了 `a`/`b`
         而 `name` / `greeting` 才是会说话的名字。留作一句提醒，不判错。

----------------------------------------------------------
【C】题 3 · 少给一个参数
----------------------------------------------------------
    题目：  link("麻黄汤")     会怎样？

    他的答案：「会报错少给参数」

    实跑（同签名的函数，独立跑，不碰他的库）：
        TypeError -> link() missing 1 required positional argument: 'ingredients_dosage'

    顺带多给一个：
        TypeError -> link() takes 2 positional arguments but 3 were given

    ✅ 判：过（说对了"报错"）
       🔑 但这条报错真正值钱的地方他没说：**报错信息点了名** ——
          它直接告诉你缺的是 `ingredients_dosage`。
          "少给/多给都报 TypeError，而且报错会说清是谁的问题" —— 这半句补上。
