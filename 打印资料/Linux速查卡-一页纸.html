🔴 先记这个，比记命令重要 —— 敲错一条就可能回不来（Linux 没有回收站）
危险写法为什么危险 / 怎么办
rm -rf * / rm -rf $VAR/删光当前目录；变量为空时等于 rm -rf / → 用 ${VAR:?} 让空值报错
> 已存在的文件直接清空原文件，无确认 → 先 cp 文件 文件.bak
kill -9 <PID>强杀，进程没机会存盘 → 先 kill <PID>，等 5 秒
chmod -R 777 .整个目录谁都能改 → 只 chmod +x 某个脚本
docker rm -f $(docker ps -q)删掉所有容器 → 先 docker ps 看清名字
铁律：不确定的命令，先 命令 --help 看一遍。 这跟你写代码前的「静态三查」是同一个习惯 —— 只不过这里查的是"这条命令会改什么"。

① 我要"找到"东西

目的命令
我在哪pwd
这目录有啥（含隐藏文件）ls -la
按文件名找find / -name "api.py" 2>/dev/null
按内容找grep -rn "8009" --include="*.py" .
按名字找（快，走索引）locate api.py
刚改过的文件ls -lt | head -6
find 按名字找，grep 按内容找 —— 两个不同的问法，别混。

② 我要"看"内容

目的命令
小文件全文cat 文件
大文件翻页（q 退出）less 文件
末尾 20 行tail -20 文件
实时跟踪新日志（最常用）tail -f app.log
有多少行wc -l 文件
只看含 ERROR 的行grep ERROR app.log
含 ERROR 的行数grep -c ERROR app.log
不要含 xxx 的行... | grep -v grep
排查问题 90% 的时候你要的是 tail -f，不是 cat。 cat 几百 MB 的日志会把终端卡死。

③ 把命令接起来（最值钱的符号）

符号意思
A | B管道：A 的输出 → 变成 B 的输入
A > f写入文件（会覆盖！）
A >> f追加到文件末尾（安全）
A 2>&1把错误输出也一起收进来（cron 里必写）
$(命令)命令替换：把输出当值用，如 N=$(ls | wc -l)
实战例：grep ERROR app.log | wc -l → 只输出一个数字
小命令拼起来能干大事 —— 这就是 Linux 的设计哲学。

④ 我要"看状态"

目的命令
8009 端口被谁占了ss -tlnp | grep 8009
老系统上的等价写法netstat -tlnp | grep 8009
按端口找进程lsof -i :8009
这进程跑了多久ps -p <PID> -o pid,etime,cmd
按名字找进程pgrep -af python
所有 python 进程数pgrep -af python | wc -l
磁盘还剩多少df -h
哪个目录最占地方du -sh */ | sort -rh | head -3
内存/负载free -h · uptime · top
PID = 进程编号，是 Linux 里"指认"一个进程的唯一方式。
一个端口同一时刻只能被一个进程监听 → "端口被占用"的本质是"那个进程还没死"。

⑤ 我要"重启 / 管服务"

情况命令
systemd 管的systemctl restart <服务名>
看它的日志journalctl -u <服务名> -f
docker 跑的docker restart <容器名>
容器日志docker logs --tail 50 <容器名>
先查清是谁在管systemctl status <名> / docker ps
用错方式重启 = 起了个野进程，然后端口冲突。
重启后必须验证：ss -tlnp | grep 8009 看 PID 变没变 + curl -s -o /dev/null -w "%{http_code}" localhost:8009/docs 是不是 200。
"命令没报错" ≠ "服务起来了" —— 跟写代码要跑测试一个道理。

⑥ 权限：读懂 -rwxr-xr-x

写法意思
r w x读=4 · 写=2 · 执行=1
755rwxr-xr-x 脚本/目录
644rw-r--r-- 配置文件，谁都不能执行
查数字形式stat -c "%a %n" 文件
给脚本加执行权chmod +x 脚本.sh → 然后 ./脚本.sh
为什么必须写 ./：当前目录默认不在 PATH 里 —— 这是安全设计，防止你 cd 到别人目录敲个 ls 却跑了他放的恶意脚本。

⑦ 卡住时的第一反应

先 命令 --help，或 man 命令（q 退出）—— 而不是来问人。
要记的是"有哪类工具"，不是拼写： 找东西 find/grep ｜ 看内容 cat/less/tail ｜ 看状态 ps/ss/df/du ｜ 改权限 chmod/chown
这跟你写 Python 从来不背 len() 一样 —— 你知道"有个东西能数字符"就够了。
